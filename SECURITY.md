# Seguridad y privacidad

## Nunca incluir en este repositorio

- Tokens, claves API, cookies, credenciales u OAuth.
- Archivos `auth.json`, `.credentials.json`, `.env` o equivalentes.
- Historiales de conversación o de terminal.
- Memorias personales del agente.
- Bases de datos locales de sesiones.
- Cachés completas de plugins.
- Rutas, nombres de proyectos o inventarios privados de una máquina concreta.

## Instalación segura

- Verifica la identidad del proveedor y la URL de origen.
- Lee `SKILL.md`, hooks y scripts antes de activarlos.
- Revisa permisos de red, filesystem y ejecución de comandos.
- Instala primero en modo deshabilitado cuando la plataforma lo permita.
- Conserva una copia de seguridad antes de cambiar configuración.
- Prueba la instalación en una sesión nueva.

## Reporte de problemas

Abre un issue sin adjuntar secretos, logs completos ni capturas que contengan información personal.
