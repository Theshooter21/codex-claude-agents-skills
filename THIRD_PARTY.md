# Skills de terceros recomendadas

Este repo **no incluye copias** de estas skills. Instálalas desde su fuente oficial, revisa su licencia y, antes de activarlas, pásalas por la skill `skill-security-review`.

| Skill | Fuente | Notas |
|---|---|---|
| `supabase`, `supabase-postgres-best-practices` | https://github.com/supabase/agent-skills | Mantenidas por Supabase; licencia MIT en la segunda |
| `accessibility`, `web-quality-audit` | https://github.com/addyosmani/web-quality-skills | Licencia MIT |
| `web-design-guidelines` | https://github.com/vercel-labs/agent-skills | Mantenida por Vercel |
| `react-doctor` | https://github.com/millionco/react-doctor | Diagnóstico de proyectos React |
| Skills oficiales de OpenAI para Codex | https://github.com/openai/skills | Se instalan con el instalador de skills de Codex |

Revisa la licencia vigente de cada repositorio antes de redistribuir. Cuando una skill no tenga fuente o licencia verificable, no la instales.
